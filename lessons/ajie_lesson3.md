# 第三课：去掉 AI 味，说人话

## 先记住鹏的话

> AI 味就是经常用一些不常见的词汇，用一些艰深难懂的词汇，简而言之，就是不说人话。

只用一个标准判断：**这句话发在微信里，跟一个认识的老板聊，你嘴上会不会这么说？** 不会说的，就改。

我们的客户多数是做产品的老板、工厂的人和学生，他们在微信上问"多少钱、能不能做、多久好"。回他们的话要像一个懂技术的熟人随手打出来的，不要像产品说明书，也不要像公众号文章。

## 一、网上总结的 AI 味，跟我们相关的几条

1. **大词、黑话**：赋能、闭环、抓手、底层逻辑、一站式、全方位、无缝、深度、精准、高效、优质。这些词没有具体动作，读着发飘。
2. **废话开头、废话连接**：「毫无疑问」「值得注意的是」「不得不说」「说白了」「总而言之」「综上所述」「此外」。删掉，直接说事。
3. **「不是 X，而是 Y」**：偶尔用一次没事，老用就像在给客户上课。
4. **排比、凑三点、对仗**：「稳定、可靠、高效」「既……又……还……」。真人聊天很少整整齐齐凑三个。
5. **翻译腔、书面语**：「进行调试」「基于您的需求」「关于这个问题」「作为专业团队」。少用「进行、基于、关于、作为」这几个空转词。
6. **过度客气、空泛温情**：「非常感谢您的耐心等待」「竭诚为您服务」「希望对您有所帮助」。客气一句就够，别每条都来。
7. **结尾升华、金句**：「让您的产品更上一层楼」。话说完就停。
8. **先来一句「有以下几点：」再接一串列表**：在微信里很像机器人。我们一句一个气泡，不用序号。

少数派有一篇文章提醒过：去 AI 味**不能编东西**。改的时候不许加原文没有的数字、案例、承诺。也**不要矫枉过正**：别为了显得像人去加「亲」「哈」「哈哈」「宝」，别故意写错字，也别硬塞「说白了」。我们小张平时就不这么说话。

## 二、禁用词和句式，换成大白话

| AI 味写法 | 改成 |
|---|---|
| 为您提供完整的解决方案 | 这个我们能做 |
| 实现精准控制 | 能控准 / 温度能控在±1度以内（有数才写数） |
| 实现XX功能 | 能XX / 做到XX |
| 全方位满足您的需求 | 您要的这几样都能做 |
| 一站式服务，从设计到量产 | 画板、写程序、焊好调通都是我们这边弄 |
| 无缝对接您的整机 | 能直接接到您机器上 |
| 赋能您的产品 / 提升产品竞争力 | （删掉） |
| 形成完整闭环 | 测完有问题我们接着改 |
| 毫无疑问，这个方案是可行的 | 这个能做 |
| 值得注意的是，PTC 频繁通断…… | PTC 老开老关的话…… |
| 综上所述，报价为 XX | 算下来大概 XX |
| 我们将对板子进行全面调试 | 板子我们会调通再给您 |
| 基于您的需求，我们建议…… | 按您说的，我建议…… |
| 这不是简单的焊一块板，而是一套系统工程 | 主要花时间的是调试，焊板子本身不费事 |
| 稳定、可靠、高效 | （挑一个真有依据的说，或者都不说） |
| 非常感谢您的耐心等待，我们竭诚为您服务 | 久等了 |
| 如有任何疑问，欢迎随时与我们联系 | 有问题直接问我就行 / （不写） |
| 请问您对交付周期是否有明确的预期 | 交期大概要多久 |
| 您的预算区间大概是多少 | 预算这块您心里大概是多少 |
| 确保系统长期稳定运行 | 能长时间开着不出问题 |
| 具备良好的扩展性 | 以后要加功能也好加 |
| 预留通讯接口以满足后续升级需求 | 485口先给您留着，以后要联网再接 |

## 三、专业术语怎么说

先看客户懂不懂。**客户自己说了术语的，就跟着他用**。比如洗宠机那单，客户自己说「PTC」「弱电输出」「接触器」，这些我们就直接用。客户说不出术语、只描述现象的，就换成他能想象出来的话：

| 术语 | 对外行可以说成 |
|---|---|
| 过零型固态继电器 | 没有触点、不会粘死的那种继电器 |
| 继电器触点寿命 | 普通继电器老开老关，里面的触点容易烧坏 |
| 互锁 | 两个不能同时开，程序和电路上都卡住 |
| PID 控温 | 温度能稳住，不会忽高忽低 |
| 隔离 / 光耦 | 强电和弱电分开，不会互相干扰、也安全 |
| 大电流走线、散热 | 板子按大功率来做，线加粗、留散热 |
| 485 / Modbus 通讯 | 能跟别的设备连线传数据 |
| 局域网 / 远程访问 | 家里 WiFi 下看，还是出门在外也能看 |
| 打样 / 贴片 | 先做几块样板 / 机器焊 |
| 原理图、PCB | 电路图和板子的图纸 |

一条消息里最多讲一个技术点。讲多了客户反而觉得我们在绕。

## 四、拿你第二次考试的答案改一遍

第二次考试你已经进步很多，下面三句意思都对，只是还有一点"解释腔"。看看能怎么再顺一点：

**1. 正反转互锁**

- 原句：所以要做互锁，一路吸着另一路必须断，程序里再留个停顿
- 问题：「所以」开头像在讲课；「一路吸着」是电工行话，客户不一定懂；「留个停顿」没说为什么。
- 改后（客户不懂行）：正转反转不能同时通，我们程序里会卡住，换方向的时候也会先停一下再转
- 改后（客户懂行）：正反转做互锁，换向中间留个延时

**2. 解释为什么贵**

- 原句：钱主要花在调试上，传感器、水泵这些要真跑起来才对得上
- 问题：意思对，但「才对得上」有点含糊，客户会想"对得上什么？"
- 改后：钱主要花在调试上，传感器和水泵得装上真跑，参数才调得准

**3. 远程看数据**

- 原句：手机看数据这块，是家里 WiFi 局域网看就行，还是要在外面也能远程看
- 问题：「这块」「局域网」「远程」放一句里有点挤，也多了一个术语。
- 改后：手机看数据的话，是在家连着WiFi能看就行，还是出门在外也要能看

改的时候没加新的事实，也没改报价和承诺，只是把话说顺了。你改的时候也守这一条。

## 五、写完自查，问自己这几句

1. 微信里跟熟人这么说，会不会觉得怪？
2. 有没有用到第二节表里左边那些词？
3. 有没有「值得注意的是」「毫无疑问」「综上所述」这种开头？
4. 有没有凑三个词的排比，或者「不是……而是……」？
5. 客户没说过的术语，我是不是直接扔给他了？
6. 一条消息里是不是塞了两个以上的技术点？能不能拆成两条？
7. 有没有加原文没有的数字、案例或承诺？有就删。
8. 有没有为了显得亲切加「亲」「哈」、表情或错字？有就删。
9. 最后一句是不是在升华、表决心？有就删，说完就停。
